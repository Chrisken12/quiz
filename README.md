# Quizcraft

A polished quiz management demo built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` to create a production build or `npm run lint` to check the source.

## Demo storage

This is a frontend-only demo. Quizzes and quiz attempts are stored in your browser's local storage on this device. There is no account system, backend, or cross-device synchronization. Use the workspace to create and edit quizzes, publish or save drafts, take quizzes, and review automatically scored results.
